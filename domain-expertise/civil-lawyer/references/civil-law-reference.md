## 1. 民法典七编核心条文速查

### 总则编（关键条文）
- **第188条**：普通诉讼时效3年（自知道或应当知道权利受损及义务人之日起）
- **第189-196条**：诉讼时效中止、中断、不适用情形
- **第143条**：民事法律行为有效条件（有行为能力 + 意思真实 + 不违法 + 不违公序良俗）
- **第148-151条**：欺诈、胁迫、重大误解、显失公平可撤销

### 物权编（关键条文）
- **第209条**：不动产物权变动以登记为生效要件
- **第223条**：动产抵押（登记对抗第三人，未登记不对抗善意第三人）
- **第312条**：遗失物不适用善意取得
- **第406条**：抵押期间抵押人可转让抵押财产（但须通知抵押权人）

### 合同编（关键条文）
- **第577条**：违约责任（继续履行/采取补救措施/赔偿损失）
- **第584条**：损失赔偿额 = 实际损失 + 合同履行后可获得的利益
- **第497条**：格式条款无效情形
- **第563条**：法定解除权（不可抗力/预期违约/迟延履行经催告/根本违约）

### 侵权责任编（关键条文）
- **第1165条**：过错责任一般条款
- **第1166条**：无过错责任须由法律规定
- **第1232条**：故意侵害自然人权益可适用惩罚性赔偿

## 2. 常见案件类型分析框架

### 2.1 合同纠纷
```
分析框架：
1. 合同是否成立（要约+承诺）
2. 合同效力（有效/无效/可撤销/效力待定）
3. 合同是否解除（法定/约定解除）
4. 违约行为认定（未履行/不适当履行/预期违约）
5. 损失计算（实际损失+可得利益+违约金调整）
```

### 2.2 侵权纠纷
```
四要件审查：
1. 侵权行为（列举行为）
2. 损害后果（量化损失）
3. 因果关系（直接/间接；必要条件规则）
4. 主观过错（故意/过失/无过错特殊侵权）

无过错侵权类型（需特别识别）：
- 产品责任（生产者）
- 机动车交通事故（保险限额内）
- 高度危险作业
- 生态环境损害
- 动物致人损害（饲养人）
```

### 2.3 婚姻家庭纠纷
```
离婚案件核心：
1. 感情破裂认定（判决离婚标准）
2. 夫妻共同财产认定与分割
   - 共同财产推定原则
   - 个人财产举证（婚前财产公证、婚内协议）
   - 隐匿财产的法律后果（少分或不分）
3. 子女抚养权（以子女最大利益为原则）
4. 债务分担（夫妻共同债务认定三标准）
```

### 2.4 继承纠纷
```
关键争议点：
1. 遗嘱效力认定（形式要件 + 实质要件）
2. 法定继承人范围（第一/第二顺序）
3. 遗产范围认定（个人财产vs共同财产）
4. 代位继承、转继承适用
5. 遗嘱执行与遗产管理人
```

### 2.5 不动产纠纷
```
常见争议类型：
- 商品房买卖合同违约（逾期交房/逾期办证）
- 借名买房（隐名权益保护）
- 阴阳合同效力
- 房屋拆迁安置纠纷
- 业主与开发商规划变更纠纷

关键证据：
- 购房合同（备案版）
- 付款凭证（银行流水）
- 交房记录
- 不动产登记证书
```

## 3. 证据规则速查

### 举证责任分配
| 情形 | 举证责任 |
|------|---------|
| 一般民事纠纷 | 谁主张，谁举证 |
| 医疗损害（违反规范/因果关系） | 医疗机构举证 |
| 生态环境损害（因果关系） | 被告举证 |
| 高危作业 | 被告举证无过错 |
| 劳动争议（规章制度/工资/考勤） | 用人单位举证 |

### 证据效力层级
1. **直接证据 > 间接证据**
2. **物证/书证 > 证人证言**
3. **原件 > 复印件**
4. **当庭质证 > 未经质证**
5. **公证证据 > 普通证据（但可被推翻）**

### 电子证据的固定
- 公证保全（最强效力）
- 区块链存证（部分法院认可）
- 截图 + 手机时间校对 + 辅助证据印证
- 第三方平台调取（需申请法院协助）

## 4. 诉讼程序关键节点

### 一审程序
```
起诉立案 → 被告答辩（15天）→ 证据交换 → 开庭审理
→ 法庭调查 → 法庭辩论 → 最后陈述 → 调解/判决
一审普通程序：6个月（可延长）
一审简易程序：3个月
```

### 关键时间节点
| 节点 | 期限 |
|------|------|
| 上诉期 | 判决书送达后15天（民事） |
| 再审申请 | 判决生效后6个月内 |
| 申请执行 | 2年（自履行期限届满之日） |
| 财产保全申请 | 起诉前/诉讼中均可 |
| 诉前保全担保 | 一般为保全金额的30% |

### 执行程序要点
- 申请执行：向一审法院或被执行人财产所在地法院申请
- 强制措施：查封、扣押、冻结、拍卖、强制腾房
- 失信被执行人名单（"老赖"）：限制高消费、出行
- 拒不执行判决罪（刑事手段）：标的较大且有能力履行

## 5. 常用计算公式

### 人身损害赔偿
```
死亡赔偿金 = 受诉法院所在地上一年度城镇（农村）居民人均可支配收入 × 20年
（60周岁以上：每增1岁减1年；75岁以上按5年计）

残疾赔偿金 = 上一年度城镇（农村）居民人均可支配收入 × 20年 × 伤残系数
（60周岁以上同上规则）

误工费 = 受害人误工天数 × 日收入（或参照同类劳动者标准）

护理费 = 护理天数 × 护理标准（护工市场价或收入损失）
```

### 利息/资金占用费
```
合同约定利率：按约定（不超过LPR的4倍）
法定利率（无约定）：同期LPR（贷款市场报价利率）
逾期利息：可约定，不超过年利率24%（司法保护上限）
```

## 6. 典型指导案例参考（民事）

最高人民法院发布的指导案例在裁判中具有重要参考价值，建议在以下领域重点检索：

- **格式条款效力**：判断提供方义务履行情况
- **情势变更**：疫情期间系列案例
- **网络侵权**：平台责任认定标准演变
- **高空抛物**：责任分配规则
- **人格权禁令**：适用条件与范围

检索渠道：最高人民法院官网 > 指导案例 / 典型案例
