# 志愿填报决策框架 · Decision Framework

> 本文件提供系统化的决策工具，供模型在输出建议时使用。

---

## 框架一：分数段 × 意向矩阵

### 高分段（600分以上 / 省内前2%）

**目标架构（冲稳保）**：
- 冲：顶尖985 + 热门专业（允许掉档风险）
- 稳：强势985 + 对口专业
- 保：重点211 + 自己感兴趣专业

**关键决策点**：
1. **有竞赛成绩/单科突出** → 优先考虑强基计划（破格通道）
2. **志向科研** → 中科大 > 985工科 >> 211（科研平台决定天花板）
3. **志向就业/创业** → 北上广深高校 + 强就业专业（计算机/金融/工科）
4. **医学意向** → 仅建议四川华西/上交大医/复旦/协和临床，其余考虑口腔/眼视光

### 中高分段（550-599 / 省内2%-10%）

**核心策略：城市优先，专业精准**

```
决策流程：
1. 确定目标城市（北上广深杭/武汉成都南京西安）
2. 该城市内找 → 该分数段可上的最强专业
3. 宁愿放弃院校综合排名，也要拿到目标行业的入场券

典型正确决策：
✅ 杭州电子科技大学计算机 vs 兰州大学生物学 → 选杭电
✅ 深圳大学计算机 vs 兰大化学 → 选深大
✅ 南京航空航天大学航空工程 vs 同济大学环境 → 看个人志向
   若志向航空→南航；若志向城市→同济（上海）
```

### 中分段（450-549）

**核心策略：行业嫡系 > 院校排名**

优先顺序：
1. 省内/区域内行业嫡系院校（电力/铁路/烟草系）
2. 行业对口专业的区域强校
3. 其次才是综合排名

**典型正确决策**：
- 理科500分 → 华北电力大学（211）电气工程 > 某普通985冷门专业
- 理科480分 → 上海电力大学电气工程 > 某普通211计算机（在上海）

### 低分段（400分以下/专科线附近）

**核心策略：手艺 > 文凭 > 一切**

```
优先级排序：
1. 铁道/电力职业技术学院（体制内正式工）
2. 民航类高职（地面服务/安检，五险一金）
3. 护理/检验类高职（医疗稳定）
4. 宠物医疗方向（宠物经济高速增长）
5. 烹饪/美发/汽修（手艺人天花板不受学历限制）
```

## 框架三：院校层次选择逻辑

### 保研率参考（适合志向深造的学生）

| 院校类型 | 推免率参考 | 说明 |
|---|---|---|
| C9高校 | 20-30%+ | 基本上成绩中上即可推免 |
| 强势985（非C9）| 10-20% | 需要在班级前10%-15% |
| 普通985 | 5-10% | 需要前5%-10% |
| 强势211 | 3-8% | 需要班级前5% |
| 普通211/双非 | 1-3% | 推免极少，靠考研 |

**结论**：若坚定要读研，进顶尖院校的中等水平，比进普通院校的第一名**更容易推免**。

### 第五轮学科评估 A+ 专业选校逻辑

```
原则：同专业下，选 A+ > A > A- > B+ > B
       不同专业下，优先选在该专业最强的院校

例：
想学船舶与海洋工程 → 上交大（唯一A+，没有对手）
想学电气工程 → 清华(A+)/华北电力(A+)/西安交大(A+)
想学口腔医学 → 四川大学华西(A+)/北京大学(A+)/上海交大
想学计算机 → 清华/浙大/北大/国防科大（多所A+）
```

## 框架四：新高考选科 → 专业准入映射

### 物理必选方向（理工主流）
- 全部理工科专业 + 计算机 + 医学 + 经济学类
- **关键提示**：选了物理，专业选择空间最大

### 历史必选方向（文科主流）
- 法学/文学/历史/哲学/教育/新闻传播/政治学/国际关系
- 经济学某些专业（部分需要物理）
- **关键提示**：历史方向可以报强基（历史类），但工科专业基本关闭

### 常见踩坑选科
- 不选物理 → 想学计算机/工科 → **专业禁入，后悔来不及**
- 选了生物不选化学 → 医学专业受限
- 选了地理不选物理 → 工科基本关闭

## 框架五：志愿报考数量与风险控制

### 平行志愿规则下的最优冲稳保比例

| 批次志愿数量 | 推荐冲稳保配置 |
|---|---|
| 6个院校 | 冲2个/稳2个/保2个 |
| 10个院校 | 冲3个/稳4个/保3个 |
| 20个院校（部分省份）| 冲5个/稳8个/保7个 |

### 平行志愿的核心误区
1. **误区**："第一志愿最重要，后面可以随便填" → 错误！平行志愿没有"第一志愿"之说，全部同等优先
2. **误区**："填满保底就能稳" → 错误！需要确认保底院校的分数线，不能只看校名
3. **误区**："专业全部填第一志愿方向" → 正确！但需要确认是否服从调剂

### 征集志愿机会
- 高考放榜后，部分院校会因生源不足发起征集志愿
- 这是低分同学进入更好院校的**二次机会**，必须密切关注
