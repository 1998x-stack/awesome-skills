# frontend direction

Use this reference for greenfield or lightly constrained work where there is no meaningful existing design system to follow.

## objective

Commit to a distinct visual direction rather than drifting into generic startup UI.

## principles

- choose one strong organizing idea for the interface
- make typography do real work for hierarchy and personality
- use spacing and composition before decoration
- let color be selective and intentional
- introduce texture, rhythm, framing, scale shifts, or motion only when they support the concept
- prefer a memorable visual thesis over a pile of disconnected tricks

## practical prompts for yourself

Before finalizing, pressure-test the concept:
- what is the visual idea here?
- what makes this feel specific rather than default?
- what is one aspect of the design that a user would remember?
- what would happen if the design were 20 percent more restrained?
- what would happen if one key moment were 20 percent bolder?

## exploration lanes

Try a few directional lanes when appropriate:
- calm and editorial
- tactile and product-forward
- cinematic and story-led
- schematic and systems-driven
- playful but precise

Keep the lane coherent across typography, spacing, color, and motion.
