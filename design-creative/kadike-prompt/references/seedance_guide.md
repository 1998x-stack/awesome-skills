## 三、短剧爆款 Prompt 写法原则

### ✅ 推荐写法
- 描述**故事情节**，让模型自动规划分镜
- 用**情绪词**而非技术词描述氛围
- **简洁突出**：故事 + 关键情绪 + 结局
- 让模型"导演"：你说故事是什么，它决定怎么拍

### ❌ 不推荐写法
- 过度描述每个镜头的技术细节（会限制模型创意）
- 台词写太长（超过4句话容易失控）
- 忽略情绪词（画面会平淡）

### 核心公式：短剧 Prompt
```
[竖屏9:16] [风格] + [开场冲突] → [中间反转] → [结局爽点]
人物特写情绪丰富，远景展示环境，近景凸显产品细节，
口型同步台词X句
```

## 四、爆款短剧类型模板（含景别安排）

### 类型一：霸总反转爽剧（适合质量卖点）
```
【风格】热门中国爽剧风格，竖屏9:16，高饱和度，15秒
【时间轴】
  0-5秒 极近景：主角被嘲讽羞辱，眼神中透着隐忍愤怒
  5-10秒 中景：主角突然冷笑，反转发生，气场骤变
  10-15秒 全景+近景切换：真实身份揭晓，对方傻眼
【口型同步】"没想到吧？（产品核心词）"
```

### 类型二：生活对比（适合面子/社交卖点）
```
【风格】现实主义农村喜剧风，竖屏9:16，暖色调，15秒
【时间轴】
  0-5秒 远景：破旧屋顶vs崭新红色坡屋顶的对比
  5-10秒 近景：路人停下来看，点头，竖大拇指
  10-15秒 特写：产品Logo出现，人物满意微笑
【口型同步】"这瓦，不一般！"
```

### 类型三：无厘头反差（最强爆款体质）
```
【风格】无厘头喜剧，戏谑风格，竖屏9:16，夸张表情，15秒
【时间轴】
  0-5秒 全景：荒诞场景（枪战/搞笑情节）发生
  5-10秒 近景：意外转折，卡地克瓷瓦出现
  10-15秒 特写：Logo清晰，旁白升华
【口型同步】最多2句，无厘头台词
```

## 五、Seedance 多素材引用技巧

### @ 素材使用规范
```
@图片1 作为主角人物参考，保持外貌一致
@图片2 作为产品卡地克红色瓷瓦参考
@图片3 作为南方农村自建房屋顶背景参考
@音频1 作为背景音乐节奏参考
```

### 优先级建议
- 3-5 张关键图 + 1-2 段参考视频 + 1 段音频
- 人物图优先（保持角色一致性）
- 产品图次之（确保瓷瓦颜色、Logo 准确）

## 六、角色一致性保持技巧

1. **提前生成角色定妆图**：生成2-3个主角备选，选定后所有镜头 @引用
2. **相同剧情描述 + 不同镜头描述**：四次生成用同一段故事背景
3. **剪映拼接**：15秒视频 × N 段 = 完整短剧
4. **首尾帧技术**：用视频延长功能接续下一个镜头

## 七、9:16 竖屏特殊注意事项

| 要点 | 说明 |
|------|------|
| 构图 | 人物居中，上下留白用于字幕 |
| 近景比例 | 近景特写要占至少1/3比例（手机用户感受强烈） |
| 字幕安全区 | 人物主体避免出现在画面最下方15%区域 |
| 产品凸显 | Logo/产品最佳位置：画面中下1/3区域 |
| 远景 | 全景镜头要展示完整建筑+天空，强化南方农村美感 |
