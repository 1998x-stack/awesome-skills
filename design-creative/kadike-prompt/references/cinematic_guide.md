# 🎥 电影级 AI 短视频制作经验手册

## 一、景别系统（必须掌握的 7 种镜头）

| 景别 | 英文 | 用途 | 卡地克应用场景 |
|------|------|------|---------------|
| 大远景 | Extreme Wide Shot | 环境交代，史诗感 | 南方农村全貌 + 远处红色屋顶 |
| 远景 | Wide Shot | 人+环境关系 | 人物站在自建房前，屋顶全景 |
| 全景 | Full Shot | 人物全身 | 主角"衣锦还乡"回家全身镜头 |
| 中景 | Medium Shot | 腰部以上，对话感 | 两人对话，面子/攀比场景 |
| 近景 | Close Shot | 胸部以上，情绪感 | 人物表情特写，发现瓷瓦 |
| 特写 | Close-up | 脸部/产品 | 瓷瓦 Logo 特写，眼神特写 |
| 极近 | Extreme Close-up | 眼睛/细节 | 红色瓷瓦釉面光泽，Logo刻字 |

### 电影感景别节奏（15秒标准公式）
```
0-3s   → 远景/全景（交代环境，建立世界观）
3-8s   → 中景+近景（发展冲突，情绪聚焦）
8-13s  → 特写+极近（产品/Logo 凸显，情绪爆发）
13-15s → 远景收尾 OR 特写定格（品牌记忆点）
```

## 二、运镜技法字典

### 基础运镜（Seedance Prompt 中直接使用）
| 运镜 | Prompt 关键词 | 情绪效果 |
|------|--------------|---------|
| 推镜 | 镜头缓慢向前推进 | 紧张、聚焦、揭示 |
| 拉镜 | 镜头缓慢后退拉远 | 孤独、环境揭示 |
| 摇镜 | 镜头左右平摇 | 环境扫描、开阔感 |
| 跟镜 | 镜头跟随人物运动 | 临场感、追逐 |
| 升镜 | 镜头缓慢向上升起 | 气势、史诗 |
| 俯拍 | 高角度俯视 | 压迫感、上帝视角 |
| 仰拍 | 低角度仰视 | 英雄感、威严 |
| 手持晃动 | 镜头微微抖动，纪实感 | 真实、紧张 |

### 高级运镜（参考电影导演风格）
- **希区柯克式**：推镜+拉焦同时进行 → 眩晕感、揭示
- **王家卫式**：慢动作+暖色调+颗粒感 → 诗意、怀旧
- **张艺谋式**：强烈色彩对比+仰拍+大景别 → 史诗、震撼
- **好莱坞动作片**：快切+手持+环境音强化 → 紧张、爽快

## 三、色彩设计原则（电影级）

### 色彩三角：情绪 × 产品 × 场景

```
红色（卡地克瓷瓦主色）
  → 激情、成功、喜庆、中国年味
  → 对比配色：金色（富贵感）/ 蓝天（清爽对比）/ 深绿树木（自然对比）

暖色调（金色/橙色）
  → 日落光打在红瓦上 → 传家宝质感
  → 早晨阳光 → 新生、希望

冷暖对比
  → 雨天灰色天空 + 红色瓷瓦 → 质量感突出
  → 旧房子灰暗 vs 新房子红瓦鲜艳 → 对比反差
```

### Seedance Prompt 色彩关键词
- `电影感暖色调，金色阳光，高饱和度`
- `逆光，背光剪影，大气感`
- `高对比度，红色视觉中心，背景虚化`
- `南方雨季，灰色天空映衬红色屋顶`

## 四、冲突设计（爆款短剧必备）

### 冲突三要素
1. **反差**：期待 vs 现实的落差（越大越好）
2. **张力**：冲突最高点前的停顿（让观众等待）
3. **反转**：出人意料的结局（无厘头 = 最强爆款）

### 卡地克专属冲突模型

**质量冲突模型：**
```
建立期待：普通瓦片容易碎/掉/褪色
↓
极端情境：用于防弹/挡枪（荒诞无厘头）
↓
反转揭示：卡地克瓷瓦安然无恙
↓
升华：这就是卡地克的品质
```

**面子冲突模型：**
```
建立对比：用杂牌瓦的邻居 vs 用卡地克的主角
↓
社交事件：相亲/走亲戚/村里聚会
↓
结果差异：主角被高看，邻居被忽视
↓
升华：盖房子，第一步选对瓦
```

## 六、音效 & 配乐选择原则

### 配乐情绪对应表
| 场景 | 配乐风格 | 关键词 |
|------|---------|--------|
| 枪战/动作 | 史诗摇滚/电子 | 紧张、爽快 |
| 面子/成功 | 国风大气 | 民族弦乐，气势磅礴 |
| 喜剧反差 | 轻快插科打诨 | 滑稽音效，反转音效 |
| 感情/传家 | 温情弦乐 | 小提琴，钢琴 |

### 音效必备清单（15秒短剧）
- 开场音效（抓人）：枪声/炸声/笑声/惊叫
- 产品出现音效：金属碰撞声/大红包收到声（喜庆）
- Logo 特写音效：低沉品牌音（KADIKE）
- 结尾收声：余韵音效
