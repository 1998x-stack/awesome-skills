## 正文全文

```
作为一个大油皮，
我人生最大的困扰不是毛孔，
是出门两小时就开始泛油光这件事😫

上妆不到中午，鼻子和T区就开始发光，
拍照全是反光…
补妆补了又厚，越补越难看。

就在我已经放弃粉底、决定裸奔的时候，
朋友推荐了这支——

✨【xxx粉底液】✨

她说："你先别买贵的，就用这个试试。"

抱着将信将疑的态度，
我在某宝30+拿下了一支。

用了第一天，下班照了下镜子，
我以为自己看错了。

T区居然没有光可以反射🤯

具体感受：
🎯 质地：清薄水感，上脸很轻，不闷
🎯 控油：T区油皮亲测，4-5小时不补妆完全没问题
🎯 遮瑕力：中等，能盖红血丝和轻微色斑
🎯 肤感：哑光但不干燥，敏感肌可以先测试

⚠️ 缺点我也要说：
遮黑眼圈和严重痘印的话遮瑕力不够，
需要叠加遮瑕膏。

📌 搭配推荐：
定妆喷雾 → 散粉 → 这支粉底的完整步骤，
可以让持妆时间再延长2-3小时，
效果更好。

现在我妈来家里，
看到我素颜以为我上了妆……🫠

油皮真的别再花大价钱了，
平价真的可以有好选择。

这支我已经回购了3次，
你们有感兴趣的评论我告诉你在哪买的～

---
#油皮护肤 #粉底推荐 #油皮粉底 #平价彩妆 #控油持妆
```

# 示例：小红书干货笔记（旅行·重庆2日游攻略）

---

## 标题

```
"第一次去重庆！狂踩坑后整理的2日游最强攻略🗺️"
```

---

## 正文

```
去重庆之前，我研究了100篇攻略，
然后还是踩了一堆坑😭

回来之后整理了这份，
把坑都帮你们踩完了⬇️

━━━━━━━━━━━━━━━━━━━

📍 Day1：解放碑→洪崖洞→千厮门大桥

10:00 解放碑步行街
→ 周边小吃超多，推荐吃胖妈烤鱼
→ 不用花太多时间，1.5小时够了

13:00 洪崖洞
→ ⚠️ 注意：白天去没什么好看的！
→ 傍晚17:00-18:00才开始亮灯，这个时候去最值
→ 建议先附近休息，晚饭前再过去

18:30 千厮门大桥
→ 过桥就能俯瞰洪崖洞全景
→ 这个角度才是你们在小红书刷到的那张图
→ 人多，要抢位置，建议18:00就位

━━━━━━━━━━━━━━━━━━━

📍 Day2：磁器口→李子坝→南山一棵树

09:00 磁器口古镇
→ 一定要早去！10点以后人多到可怕
→ 必买：麻花、陈麻花（不是一个）、椒盐花生
→ 用1.5-2小时走完

12:00 李子坝站
→ 就是轻轨穿楼那个！！
→ 在马路对面等，轻轨大概5-8分钟一趟
→ 建议正午人少的时候去

16:00 南山一棵树观景台
→ 夜景最出名的地点
→ 打车上去，20分钟左右
→ 傍晚到了等日落+亮灯，双倍快乐✨

━━━━━━━━━━━━━━━━━━━

💰 费用参考（两人）
机票：往返约800-1200元/人（淡季）
住宿：解放碑周边民宿约200-350元/晚
餐饮：人均50-80元/天（重庆物价还行）
门票：基本都免费！！！

🚫 踩坑避雷
❌ 不要去"网红打卡地"旁边的餐厅，贵且难吃
❌ 不要中午去洪崖洞
❌ 不要坐景区专线，普通公交+打车更方便

━━━━━━━━━━━━━━━━━━━

这份攻略是我去过之后真实整理的，
图片全是自己拍的哈！

还有什么想问的评论区聊～
下次打算整理一份美食版💕

---
#重庆旅游 #重庆攻略 #重庆2日游 #旅行攻略 #洪崖洞
```
