# 示例：知识干货类脚本（抖音·60秒·职场方向）

---

## 基本信息

- **平台**：抖音
- **时长**：60秒
- **类型**：知识干货类（口播）
- **目标受众**：25-35岁职场打工人
- **核心价值**：教用户3个职场沟通技巧
- **目标行为**：收藏 + 关注

---

## 完整口播台词

```
[钩子·0-5秒]
为什么有些人在职场上，
明明没你努力，
升职却比你快？

[建立权威·5-10秒]
做了8年HR，面试过3000多个人，
我发现这不是能力的问题，
是沟通方式的问题。

[中段钩子预告·10-12秒]
分享3个让你立刻不一样的方法，
第三个很多人做了但不知道，
一定要看完。

[第1条·12-25秒]
第一，汇报工作，先说结论。

很多人喜欢一上来就把过程全讲完，
等说完了，领导问你——"那你结论是什么？"
那就尴尬了。

正确的方式是：
先说结论，再说依据，再说方案。
三句话搞定，让对方知道你有条理。

[第2条·25-38秒]
第二，提问题，先给方案。

不要只是拿着问题去找领导，
而是要把你的思考一起带过去：
"有个问题，我目前的想法是A/B/C，你看哪个更合适？"

这一句话，让你从"等待被安排"变成"主动推进者"，
差别非常大。

[第3条，高潮·38-52秒]
第三条——很多人做了，但不知道为什么有效：

重复领导说过的话。

比如会议结束，你去找领导确认：
"刚才您提到要优先推A方向，我的理解是……对吗？"

这个动作，让对方感觉被重视、被听见，
同时帮你避免了执行偏差。
表面是确认，实质是建立信任。

[收尾金句·52-57秒]
职场沟通的本质不是表达，
是让对方愿意继续和你说话。

[CTA·57-60秒]
先收藏，职场上一定用得上。
你还有哪些沟通困惑，评论区告诉我。
```

---

## 数据预期与优化建议

- **预期完播率**：>35%（知识类平均水平）
- **预期收藏率**：>2%（实用性强，收藏驱动）
- **优化建议**：
  1. 第3条"重复领导的话"若反响好，可单独做一条视频深度展开
  2. 钩子可A/B测试：方案A（"为什么升职比你快"）vs 方案B（"我见过的最聪明的职场人都会这3件事"）
  3. 评论区预设引导：置顶一条"你遇到最难搞的沟通场景是什么"

# 示例：带货类脚本（抖音·45秒·清洁产品）

---

## 完整口播台词 + 分镜对照

```
[0-3s] ← 视觉钩子（无台词）
画面：锅底满是油污 → 一喷清洁剂 → 5秒后变干净
字幕大字：这玩意儿不是智商税？！

[3-10s] ← 痛点共鸣
台词："每次洗碗最头疼的就是这种油腻腻的锅，
      用洗洁精搓半天，还是油乎乎的，
      关键手还难受……"

[10-25s] ← 产品展示
台词："直到用了这个——
      喷上去，等30秒，
      直接用湿布一擦，
      你看，干净了。
      [停顿]
      真的一点都不用使劲。"

[25-35s] ← 信任建立
台词："我已经用了三个月了，
      成分表我查过，不含荧光剂，
      家里有娃的也可以放心用。
      现在我妈来我家，
      都问我这是什么东西。"

[35-42s] ← 价格+福利
台词："之前在超市买过类似的，
      一瓶40多块，
      这个同款工厂的，
      三瓶才XX元，
      购物车我放好了。"

[42-45s] ← CTA
台词："觉得有用就收藏，
      不然等会儿找不到了。"
```

# 示例：情感共鸣类脚本（抖音·30秒·治愈向）

---

## 背景与目标

- **目标**：高分享率 + 点赞
- **情绪设计**：代入感 → 情绪递进 → 触动 → 释放

---

## 完整台词

```
[代入·0-5s]
你有没有那种感觉——

明明很累，
却睡不着。

[递进·5-15s]
不是因为烦，
只是太多事，
堆在心里，
没地方放。

这种累，
不是身体的那种累，
是那种……说不出来，
但你懂的。

[高潮·15-25s]
你不是脆弱，
你只是太久没有被好好对待了——

包括被你自己。

[收尾·25-30s]
今天就这样吧。
先休息，
明天再说。
```

**后期制作建议：**
- BGM：低缓钢琴曲，无歌词
- 字幕：白色细体字，慢慢出现（逐字显示）
- 画面：夜晚城市空镜 / 窗边灯光 / 手机屏幕
- 无需出镜，纯声音 + 画面
