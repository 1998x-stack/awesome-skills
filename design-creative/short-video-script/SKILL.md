## 工作流程

### Step 1：信息采集（必做）

在动笔前，务必向用户收集以下信息（如果已知则跳过）：

**必须确认：**
- **平台**：抖音 / 小红书 / 视频号 / 快手 / TikTok
- **视频时长目标**：15s / 30s / 60s / 3-5min
- **内容类型**：知识 / 带货 / 剧情 / 情感 / Vlog / 品牌
- **目标受众**：（年龄/性别/职业/痛点）
- **核心卖点或主题**：（一句话概括）
- **期望达成的用户行为**：点赞 / 收藏 / 购买 / 关注 / 评论

**选填（能大幅提升质量）：**
- 账号人设/风格参考
- 是否需要口播台词
- 是否需要分镜描述
- 竞品/对标账号

### Step 2：选择脚本框架

根据内容类型匹配对应框架（详见 References）：

- **知识类** → HOOK + 建立权威 + 干货分步 + 中段钩 + 总结金句 + CTA
- **带货类** → HOOK + 痛点共鸣 + 产品相遇 + 效果呈现 + 信任背书 + CTA
- **剧情类** → 冲突建立 + 激化 + 反转 + 情绪释放 + 金句收尾
- **情感类** → 场景代入 + 情绪递进 + 共鸣高潮 + 升华/行动

### Step 3：撰写脚本

**必须包含的要素：**
1. **黄金3秒开头**（见 `references/douyin_script.md` → 钩子库）
2. **中段留存钩子**（悬念/彩蛋/序号引导）
3. **节奏感**（去废话，每句话有存在意义）
4. **口语化**（文案要说得出来，而不是写得好看）
5. **CTA 设计**（引导具体行为，不要泛泛说"关注我"）

### Step 4：输出格式

根据用户需求选择输出格式：

**格式A：完整口播台词**（适合口播类）
```
[开头钩子] 3-5 秒
[主体内容] 逐句口播台词，带时间估算
[收尾+CTA] 3-5 秒
总字数：约 XXX 字 / 约 XX 秒
```

**格式B：分镜脚本**（适合剧情/带货类）
```
| 镜号 | 时间 | 画面描述 | 台词/字幕 | 音效/BGM | 拍摄要求 |
|-----|------|---------|---------|---------|---------|
|  1  |  3s  |  ...   |  ...   |  ...   |  ...   |
```

**格式C：标题+正文**（适合小红书图文）
```
标题选项（3个，供用户选择）
封面图文案建议
正文（分段，带 Emoji，结尾带互动句+标签）
```

## 核心写作原则

### 黄金3秒公式（必须遵守）

```
任何脚本的第一句话必须满足以下三个条件之一：
① 制造信息缺口（让用户产生"我必须看完才知道"的感觉）
② 触发高唤醒情绪（惊讶/愤怒/焦虑/敬畏）
③ 精准锁定目标受众（"所有XX人听好了"）

禁止使用的开头：
✗ "大家好，我是XXX"
✗ "今天来分享一下..."
✗ 风景空镜 + 抒情音乐（慢热型）
✗ 超过3句话才到重点
```

### 情绪设计原则

参照 Berger 情绪传播研究：
- **收藏驱动**：焦虑感 + 实用价值（"不看后悔"型）
- **分享驱动**：惊讶/敬畏/幽默（"你看这个！"型）
- **评论驱动**：争议 + 共鸣（"这就是我！"或"我不同意！"）
- **点赞驱动**：感动 + 认同（"说出了我的心声"）

### 口语化改写规则

书面文字 → 口播文字：
- 长句拆短句（不超过15字/句为宜）
- 删去所有"的"字前可省略的内容
- 加入语气词（嗯、对、就是说、你知道吗）
- 数字写成发音形式（"3"→"三个"）
- 停顿标记：… 或 [停顿]

## 快速参考：爆款钩子速查表

### 痛点型
- `千万别再XXX了！XX%的人都做错了`
- `你还在用XXX？难怪效果这么差`
- `为什么你XXX总失败？因为没人告诉你这件事`

### 利益型  
- `我花了X万，现在免费分享给你`
- `刷到就是赚到！今天免费送XXX`
- `不知道这个，你要多花X倍的钱`

### 悬念型
- `当[人物]做了[行为]之后，发生了…`
- `所有人都以为[假象]，结果…`
- `这件事我犹豫了很久要不要说`

### 反常识型
- `你以为[常识A]，其实[颠覆B]`
- `[权威人士]竟然说[出乎意料]`
- `这个方法被99%的人忽视了`

### 人群锁定型
- `所有[精准人群]听好了`
- `[职业/状态]的人必看`
- `如果你也[处境/感受]，这条视频专门为你拍的`

## 平台差异速查

| 要素 | 抖音 | 小红书 | 视频号 |
|------|------|--------|--------|
| 语气 | 娱乐化，接地气 | 闺蜜分享感，真实 | 偏生活/正能量 |
| 开头 | 视觉冲击或语言钩子 | 场景代入+痛点 | 情感共鸣 |
| 节奏 | 快，信息密度高 | 较慢，有温度 | 中等 |
| CTA | 点赞/关注/购物车 | 收藏/评论/私信 | 分享到朋友圈 |
| 禁忌 | 绝对化词汇，涉嫌违规 | 硬广感，关键词堆砌 | 低俗/争议 |
| SEO | 弱（标签） | 强（搜索关键词） | 弱 |

## 输出质量检查清单

在交付脚本前，自检以下项目：

- [ ] 前3句是否有足够吸引力（是否会被划走？）
- [ ] 是否有中段留存钩子（防止中途划走）
- [ ] 台词是否口语化（说出来顺不顺？）
- [ ] 是否有明确的 CTA（用户看完应该做什么？）
- [ ] 情绪设计是否与目标行为匹配
- [ ] 总时长是否符合平台最优区间
- [ ] 是否包含目标关键词（SEO价值，尤其小红书）
- [ ] 是否避免了违规词汇
