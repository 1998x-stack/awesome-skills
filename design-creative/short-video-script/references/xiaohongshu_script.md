# 小红书图文 & 短视频脚本框架

## 一、小红书平台核心逻辑

```
推荐机制（三并重）：
① 搜索流量（SEO）：用户主动搜索关键词
② 关注流量：粉丝更新推送
③ 发现流量：算法推荐（基于兴趣标签）

最重要指标：收藏 > 点赞 > 评论 > 转发
（收藏代表真实价值认可，权重最高）
```

**小红书用户心理：**
- 有明确需求（搜索驱动）
- 相信"真实用户分享"
- 对"硬广感"高度排斥
- 视种草笔记为"闺蜜推荐"

## 二、爆款笔记四大要素

```
选题 → 封面/首图 → 标题 → 正文
 ↓         ↓         ↓       ↓
决定上限  决定点击率  决定读文率  决定收藏/互动
```

## 三、选题方法论

### 3.1 三种选题来源

**① 关键词需求挖掘**
- 使用平台搜索框，输入关键词看联想词
- 灰豚数据 / 新红 查搜索量趋势
- 规则：搜索量大 + 竞争小 = 最优选题

**② 爆款拆解模仿**
- 找垂类 TOP20 博主，拆解其点赞/收藏最高的内容
- 分析：选题方向/标题格式/正文结构/图片风格
- 模仿结构，内容做差异化

**③ 痛点-需求矩阵**
```
用户画像 × 生活场景 × 痛点 = 内容选题

示例：
目标用户：职场新人 25岁女性
生活场景：工作面试/初入职场
核心痛点：穿搭不知道怎么搭/形象焦虑
→ 选题："面试穿搭踩雷指南！HR最讨厌这几种"
```

## 四、标题写作系统

### 4.1 六大标题类型

**① 痛点+解决方案型**
```
公式：[具体痛点关键词] + [解决方案亮点]
示例：
"油皮每天爆油？5分钟学会这个让你素颜被夸好气色"
"熬夜脸怎么救！早八打工人的遮瑕急救包来了"
```

**② 数字量化型**
```
公式：[时间/数量] + [转变对比] + [结果可视化]
示例：
"28天换头计划！塌鼻梁→妈生鼻的修容地图"
"花了3000学费，总结出这7条面试必知"
```

**③ 社交认证型**
```
公式：[他人追问/认证] + [具体内容]
示例：
"被闺蜜追着要链接的3支口红！黄黑皮亲妈显白"
"被追问800次的伪素颜密码！"
"室友看到都问链接的租房改造"
```

**④ 反差冲突型**
```
公式：[高期待/误判] vs [真相/低成本]
示例：
"被邻居误认豪宅的客厅！其实全是1688同源厂"
"出租屋爆改婚房！房东看到直说免三年租金"
"看起来1000块的穿搭，其实全部加起来不到300"
```

**⑤ 人群标签型**
```
公式：[精准人群描述] + [专属内容]
示例：
"油痘肌早八人速码！"
"新手妈妈必看！这些坑我替你踩过了"
"北漂/沪漂第一年不踩坑指南"
```

**⑥ 好友对话型**
```
公式：[你/我/宝子]+[行动词]+[内容]
示例：
"宝子们，这个真的要冲！！"
"姐妹们我发现了一个宝贝"
"快来看！这个我藏了好久终于舍得分享"
```

### 4.2 标题必备元素

```
核心关键词（1-2个）：用户搜索时会用的词
情绪词（可选）：宝藏/绝了/救命/冲/速码/必看
感叹号/问号：增加语气张力（适量使用）
Emoji：！🔥💡✨（小红书风格，不超过3个）
字数：20字以内（平台显示上限）
```

### 4.3 标题禁忌

- ✗ 平铺直叙（"分享我的日常护肤步骤"）
- ✗ 关键词缺失（用户搜不到你）
- ✗ 假大空（"超级好用！！！"没有具体信息）
- ✗ 标点堆砌（"！！！！！！！"）

## 五、首图设计指南

### 5.1 货架思维

> 用户在小红书发现页浏览时，你的笔记是货架上的商品，首图是包装。核心：在0.1秒内让目标用户停下来。

### 5.2 首图类型与适用场景

| 类型 | 适用内容 | 设计要点 |
|------|---------|---------|
| **对比图** | 美妆/改造/减肥 | 前后差异要极致显眼 |
| **产品平铺** | 好物分享/合集 | 整洁美观，物品有设计感 |
| **人物出镜** | 穿搭/生活方式 | 颜值/状态要突出 |
| **文字主图** | 干货/攻略/清单 | 字体清晰，色彩鲜明 |
| **场景氛围** | 旅行/美食/探店 | 高质感构图，情绪到位 |

### 5.3 首图文案设计

```
经典布局：
┌─────────────────────┐
│ [痛点问题]           │← 左上角
│                      │
│                      │
│          [产品/结果图]│
│                      │
│ [解决方案亮点]       │← 右下角
└─────────────────────┘

尺寸：3:4 竖图（1080×1440px）
颜色：高对比度，与竞品差异化
字体：清晰可读，关键词加粗
```

## 六、正文结构模板

### 6.1 种草文公式（使用频率最高）

```
① 【痛点引入】
   "我这段时间一直被[具体问题]困扰着..."
   （具体场景描述，让用户代入）
   
② 【相遇产品/方法】
   "就在我快放弃的时候，[朋友推荐/偶然发现]了这个..."
   （真实感叙述，降低广告感）
   
③ 【使用过程】
   "用了[时间]之后，[阶段性效果]..."
   "具体方法是：[步骤细节，加时间节点]"
   
④ 【效果呈现】（可视化最重要）
   "用前 → 用后的变化是..."
   "数据/比较数据"
   "上图，让你们自己看"
   
⑤ 【客观评价】（增加可信度）
   "缺点也有：[诚实列出1-2个缺点]"
   "适合人群：[具体描述]"
   
⑥ 【行动引导】
   "有同样困扰的宝子可以来评论区聊聊～"
   "还有什么想了解的评论告诉我"
```

### 6.2 干货/攻略类公式

```
[核心结论句]（让读者知道能得到什么）

📌 [要点1]
   具体说明（2-3行）
   
📌 [要点2]
   具体说明（2-3行）
   
📌 [要点3（最有价值的放第3条）]
   具体说明（2-3行）

💡 总结
   最重要的一句话

❓ 互动
   "你们有遇到过这种情况吗？"
   "还有哪个方面想了解？"

---
#话题标签1 #话题标签2 #话题标签3（3-5个，精准匹配）
```

### 6.3 好物合集/清单类公式

```
[开头总结句]："整理了X个/套[类别]，真的都买了试过！"

No.1 [产品名]
📍价格：xxx元
✅ 优点：[2-3个核心优点]
❌ 缺点：[1个客观缺点，增加可信度]
🎯 适合：[具体人群]

No.2 [产品名]
（同上格式）

最后：
[总体购买建议]
[互动句：你们有用过哪个？]
```

## 七、小红书 SEO 策略

### 7.1 关键词布局规则

```
标题：1-2个核心搜索关键词（自然融入，非堆砌）
正文开头：出现1次关键词
正文中段：每隔2-3段自然出现1次
标签：精准话题标签3-5个
    ├── 大类标签（如：#护肤）
    ├── 中类标签（如：#油皮护肤）
    └── 精准标签（如：#油痘肌日常护肤）
```

### 7.2 避免降权的操作

- 关键词密度：不能在同一段落连续出现3次以上
- 错误示例：`"这款口红是我用过的口红里最好的口红"`
- 正确示例：`"这款口红真的太好用了，质地超滋润，颜色正"`

### 7.3 搜索流量获取路径

```
用户搜索"[关键词]"
    ↓
你的笔记出现在搜索结果第3名以内
    ↓
持续获得精准流量
    ↓
收藏量积累 → 算法识别为"有价值内容" → 更多曝光
```

## 八、互动设计：让评论区活起来

### 8.1 评论区引导技巧

**开放式提问（最有效）：**
- "你们平时有遇到这种情况吗？"
- "你觉得哪个最适合你？"
- "还有什么想了解的告诉我！"

**选边站设计（制造讨论）：**
- "你是A类人还是B类人？评论区告诉我"

**信息征集（增加参与感）：**
- "你们还有什么好用的推荐？分享在评论区！"

**悬念引导（带来回复互动）：**
- "第二张有惊喜，滑过去看看"
- "评论区见，有问题我都回答"

### 8.2 评论区维护

- 置顶关键补充信息（防止重复提问）
- 回复前10条评论（平台机制倾斜）
- 设置一条"引导性评论"作为讨论起点

## 九、不同品类特殊要点

### 美妆/护肤类
- 肤质/肤色/年龄精准标注（"干皮/油皮/混皮"）
- 前后对比图是标配
- 专业词 + 口语结合（"光泽感/玻尿酸"+"嫩嫩的/水水的"）

### 穿搭类
- 体型参考（身高体重要写）
- 场合标注（上班/休闲/约会）
- 单品链接/替代方案（降低购买门槛）

### 美食/探店类
- 地址/营业时间/价位必写
- 必点推荐（具体到菜名）
- 避坑信息（排队情况/停车/位置）

### 旅行攻略类
- 交通/住宿/行程结构清晰
- 费用估算（预算参考）
- 时间标注（几月去/游玩时长）

### 职场/干货类
- 具体可操作（不要只讲道理）
- 数字化/可量化
- 个人经历背书（增加可信度）
