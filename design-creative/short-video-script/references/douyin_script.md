# 抖音 / 快手 / 视频号 脚本详细框架

## 一、平台核心逻辑

```
抖音算法评分 = f(完播率, 互动率, 分享率, 关注转化率)
    ↓
完播率权重最高（前3秒留存决定一切）
    ↓
互动率 = (点赞+评论+收藏+分享) / 播放量
```

**最优视频时长区间**
- 爆款高发区：15-30秒（娱乐/情绪类）
- 知识类：60-90秒
- 剧情类：1-3分钟
- 深度内容：5-10分钟（需要强叙事能力）

## 二、五类脚本完整框架

### 2.1 知识干货类脚本框架

```
┌─────────────────────────────────────────────────────┐
│ 【HOOK 0-5s】痛点/反常识/数字型钩子                   │
│   模板："为什么你XXX总失败？因为没人告诉你这3个真相"    │
├─────────────────────────────────────────────────────┤
│ 【建立权威 5-10s】                                    │
│   "从业X年/花了X钱/亲测有效/专业背景"                 │
├─────────────────────────────────────────────────────┤
│ 【序号提示 10s】                                      │
│   "第X条最重要，一定要看完"（植入中段钩子）             │
├─────────────────────────────────────────────────────┤
│ 【干货内容 10-50s】逐条输出（每条≤15s）               │
│   第一个：[最基础/共鸣最强]                           │
│   第二个：[进阶/转折]                                 │
│   第三个：[最有价值/最意外]（高潮设计在第3条）          │
├─────────────────────────────────────────────────────┤
│ 【总结金句 50-55s】                                   │
│   可被截图/引用的精华句子（社交货币设计）              │
├─────────────────────────────────────────────────────┤
│ 【CTA 55-60s】                                       │
│   "先收藏，下次遇到就不慌了"（收藏型）                 │
│   "你遇到过这种情况吗？评论区聊聊"（评论型）           │
└─────────────────────────────────────────────────────┘
```

**知识类脚本禁忌：**
- ✗ 一开始介绍自己（用户不关心你是谁）
- ✗ 铺垫太长（超过5秒没进入重点）
- ✗ 术语堆砌（要"下沉化"，像朋友聊天一样）
- ✗ 废话套话（"好的，我们开始吧"等）

### 2.2 剧情演绎类脚本框架

**冲突三幕式结构：**

```
第一幕：建立（0-8s）
  ├── 场景快速建立（1-2个镜头）
  ├── 人物关系/状态快速交代
  └── 冲突引爆点投出（HOOK）

第二幕：激化（8-20s）
  ├── 冲突升级（至少一个意外）
  ├── 情绪推进（观众焦虑/期待）
  └── 中段钩子："接下来发生的事让我没想到"

第三幕：解决（20-30s）
  ├── 反转/意外结局
  ├── 情绪释放（笑/感动/惊讶）
  └── 金句收尾（可选）
```

**反转设计三层级：**
1. 小反转（15s内）：视觉反转（换妆/场景切换）
2. 剧情反转（30-60s）：人物立场/关系的颠覆
3. 价值观反转（1-3min）：深层认知的重构

**提升剧情张力的技巧：**
- 反差设定：高地位+低姿态 / 强外表+软内心
- 时间压力：倒计时 / 截止日期
- 信息不对称：观众知道但角色不知道
- 多线并进（复杂剧情）：AB线交织

### 2.3 带货展示类脚本框架

```
五步带货链：
① 信息位确定（用户真正决策的点是什么，不是你认为的卖点）
② 开头吸引（五种吸引点选其一）
③ 决策关键环（消除顾虑/提供保证）
④ 转化逻辑链（为什么是这个，而不是其他）
⑤ 行动指令（购物车/链接/评论区）
```

**五种开头吸引点**
| 类型 | 适用品类 | 示例 |
|------|---------|------|
| 效果展示 | 美妆/家居清洁 | 0秒直接展示产品效果 |
| 痛点共鸣 | 健康/效率工具 | "你也有这个问题吗" |
| 价格锚定 | 性价比商品 | "这个价格你不可能找到更好的" |
| 权威背书 | 专业类商品 | "医生/大厂工程师推荐" |
| 情绪价值 | 国货/老品牌 | "国货之光终于被发现了" |

**产品展示节奏**
```
0-3s：视觉冲击（产品最佳效果/最亮眼画面）
3-10s：痛点共鸣（用户为什么需要它）
10-25s：产品展示（功能/使用过程/对比）
25-35s：信任建立（评价/数据/背书）
35-40s：价格/福利（锚定+优惠）
40-45s：CTA（购物车/评论区）
```

### 2.4 情感共鸣类脚本框架

**情绪递进模型（峰终定律应用）：**

```
情绪强度
    ↑
    │          ╱╲
    │        ╱  ╲
    │      ╱    ╲_________（情绪峰值）
    │    ╱
    │  ╱
    │╱
    └────────────────────── 时间
   代入  递进   高潮   收尾
```

**四阶情感脚本：**
1. **场景代入**（让用户说"这就是我"）
2. **情绪递进**（逐步加深情感共鸣）
3. **情绪爆发**（泪点/笑点/触动点）
4. **升华收尾**（留下余韵/金句/意义）

**高传播情感选题方向：**
- 关系类：父母/伴侣/友情的感人瞬间
- 成长类：普通人克服困难的真实故事
- 时代类：集体记忆/共同经历
- 身份认同：职业/地域/生活方式认同

### 2.5 挑战/UGC 引导类脚本框架

```
标准结构：
[引入挑战]：你敢不敢挑战XXX？
[示范展示]：创作者先演示一遍
[邀请参与]："@朋友来挑战"/"你能做到吗？"
[模板提供]：BGM、格式、标签（降低参与门槛）
```

**高参与度设计要素：**
- 门槛适中（太难没人做，太简单没传播）
- 有展示自我的空间（社交货币）
- BGM朗朗上口（形成条件反射）
- 结果有差异感（每人做出来不一样更有意思）

## 五、口播稿润色要点

**五步口播化改写：**

1. **拆句**：超过20字的句子，找逻辑断点拆开
2. **去"的"**：删减不必要的"的/地/得"
3. **加语气词**：开头/结尾加上"嗯""对""就是说""你知道吗"
4. **口语替换**：书面词→口语词（"因此"→"所以""然而"→"但是"）
5. **节奏标注**：用 [停顿] / … 标记呼吸节点

**示例改写：**
```
原文（书面）：
"使用这款产品，可以有效改善您的睡眠质量，提升日间精力水平。"

改写（口播）：
"用了这个之后，[停顿]
你会发现晚上睡得特别香，
第二天起来，精神状态直接不一样了。[停顿]
真的不骗你。"
```

## 六、分镜脚本模板

### 标准分镜格式

| 镜号 | 时长 | 景别 | 画面内容 | 台词/字幕 | BGM/音效 | 备注 |
|-----|------|------|---------|---------|---------|------|
| 01 | 3s | 特写 | 产品炸裂效果 | "这效果是真的？！" | 鼓点+惊讶音效 | 正面灯光，慢动作 |
| 02 | 5s | 中景 | 主播出镜说话 | "我试了市面上100款..." | 无BGM | 自然光，背景简洁 |
| ... | ... | ... | ... | ... | ... | ... |

### 景别参考
- **大全景**：交代环境/场景
- **全景**：展示人物全貌
- **中景**：人物上半身，日常交流
- **近景**：人物胸口以上，情感表达
- **特写**：面部/产品细节，强调重点
- **大特写**：局部细节，情绪强化

### 运镜参考
- 推镜头：强调重点，产生压迫感
- 拉镜头：揭示环境，释放情绪
- 摇镜头：展示空间，跟踪运动
- 跟镜头：增加真实感，临场感
- 手持：真实粗粝感，适合Vlog/剧情
