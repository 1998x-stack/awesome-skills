# Translation Patterns

Use these conversions when rewriting a draft.

## Pattern 1: 从人物评判到制度解释

Instead of:
- “皇帝昏庸导致局势恶化。”

Rewrite toward:
- “局势恶化不能只归因于君主个人能力，还要看财政、信息和地方控制能力是否足以支撑既有统治规模。”

## Pattern 2: 从忠奸叙事到组织失灵

Instead of:
- “朝廷被奸臣把持，改革失败。”

Rewrite toward:
- “改革失败表面上表现为人事斗争，深层则涉及既有官僚文化、激励结构与行政接口不支持新的治理方式。”

## Pattern 3: 从道德败坏到技术不可行

Instead of:
- “官场风气败坏，所以制度无法运行。”

Rewrite toward:
- “制度运行不良不只是士风问题，也可能是统计、核算、审计和问责链条缺失，导致治理过度依赖道德自律。”

## Pattern 4: 从集权强到治理强

Instead of:
- “中央集权加强，所以国家能力增强。”

Rewrite toward:
- “形式上的集权并不自动转化为信息掌握、财政控制与基层执行能力，必须区分权威象征与操作能力。”
