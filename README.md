```bash

cd awesome-skills

# 查看所有 Skills
ls skills/

cat skills/karpathy-skills/README.md
```

## 📝 添加新 Skill

1. 在 `skills/` 目录下创建新文件夹
2. 添加 `SKILL.md` 作为入口文件
3. 可选添加 `references/`, `scripts/`, `agents/` 等子目录
4. 更新本 README
