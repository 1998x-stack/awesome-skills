# Awesome Skills 🛠️

A curated collection of high-performance agent skills designed to enhance AI autonomy, research capabilities, and creative workflows. This repository serves as a central hub for modular expertise that can be integrated into various AI agent frameworks.

## 📂 Directory Structure

| Category | Skills | Description |
| :--- | :--- | :--- |
| **🤖 Agent Harness** | `agent_harness`, `autonomous-research` | Core logic for managing sub-agents and conducting deep-dive research. |
| **🎨 Design & UI** | `claude-design`, `html-design-manager`, `godot-engine` | Tools for visual aesthetics, HTML management, and game engine integration. |
| **🧠 Innovation & Strategy** | `bottom-up-innovation`, `musk-guidelines`, `history-guidelines` | Frameworks for first-principles thinking and historical context analysis. |
| **⚙️ Engineering & Dev** | `taptap-maker-issue-builder`, `prefab-search` | Utilities for issue tracking, code search, and development workflows. |
| **📊 Analysis & Eval** | `skill-eval`, `model-pricing-visualizer` | Metrics for evaluating skill performance and visualizing model costs. |
| **🗣️ Local Extensions** | `agent-skills`, `dashscope-asr` | Integrated professional skill sets and custom voice transcription tools. |

## 🌟 Featured Skills

- **Autonomous Research**: Enables agents to perform multi-step, self-directed investigations with citation tracking.
- **Musk Guidelines**: Implements first-principles reasoning patterns for complex problem-solving.
- **HTML Design Manager**: A specialized skill for maintaining consistency in web-based UI/UX projects.
- **DashScope ASR**: High-precision speech-to-text transcription powered by Alibaba Cloud's Paraformer model.

## 🚀 Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/1998x-stack/awesome-skills.git
   ```
2. **Integrate**: Copy the desired skill folders into your agent's `skills/` directory.
3. **Configure**: Update your agent's system prompt to reference the new skill definitions.
