## Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/1998x-stack/awesome-skills.git
   ```
2. **Browse by category** — each category folder contains related skills.
3. **Integrate** — copy desired skill folders into your agent's `skills/` directory.
4. **Configure** — update your agent's system prompt to reference the new skill definitions.

## Skill Format

Individual skills follow the `SKILL.md` convention with YAML frontmatter (`name`, `description`) that controls auto-triggering behavior. Collection projects may have their own conventions — check each project's CLAUDE.md or CONTRIBUTING.md.
