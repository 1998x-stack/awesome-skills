## 二、卡地克场景最佳配音选择

### 🔥 TOP 1：农村大叔腔（最强推荐）
**适用场景**：建房决策、质量展示、长辈口吻
**语言特征**：
- 带点地方口音（湖南/江西/广西普通话）
- 语速适中，有停顿感
- 朴实有力，说话"一是一，二是二"
- 结尾常用：`讲真的！/ 这个靠谱！/ 搞清楚！`

**示例台词**：
```
"这个瓦，好！"
"我建房，就选卡地克！"
"邻居都来问我，哪里买的瓦？"
```

**Seedance 配音 Prompt**：
```
配音采用中年男声，带轻微湖南/江西口音，语气朴实自信，
节奏慢而有力，带些许自豪感
```

---

### 🔥 TOP 2：无厘头旁白腔（最强爆款体质）
**适用场景**：枪战防弹场景、荒诞无厘头短剧
**语言特征**：
- 语速忽快忽慢，制造反差
- 夸张的情绪切换
- 傅首尔/周星驰附体感
- 结尾突然认真：`这就是卡地克！`

**示例台词**：
```
"（平静）哎，这枪打在瓷瓦上..."
"（惊讶）怎么没事？！"
"（肃然）因为这是——卡地克！"
```

**Seedance 配音 Prompt**：
```
旁白风格，普通话带搞笑腔，语气反差强烈，
前半段漫不经心，后半段突然严肃，配合画面节奏
```

---

### 🔥 TOP 3：霸总反转腔（年轻群体爱看）
**适用场景**：相亲、面子、衣锦还乡
**语言特征**：
- 前段低沉被压制
- 中段冷笑一声
- 后段云淡风轻的霸气
- 带有 BGM 感

**示例台词**：
```
（被嘲）"你们村用什么瓦？"
（冷笑）"卡地克。"
（对方愣住）"..."
```

**Seedance 配音 Prompt**：
```
男主声音先低沉压制，在"卡地克"一词时语速放缓、气场骤升，
背景配合史诗音效，口型同步精确
```

---

### 🔥 TOP 4：南方方言腔（地域亲切感）
**适用场景**：面向湖南/江西/广西/广东用户
**语言特征**：
- 粤语/湘语腔普通话
- 说话直接，不绕弯子
- "这个瓦靓！" "实在！"
- Seedance 1.5 Pro 支持方言生成

**示例台词**：
```
"你看哈，这个瓦，好靓啊！"
"用了卡地克，建房不后悔！"
```

**Seedance 配音 Prompt**：

```
支持粤语方言口音的普通话，亲切自然，语速轻快，
带南方地区特有的爽朗语调
```

---

### 🔥 TOP 5：媒人/红娘腔（相亲场景必备）
**适用场景**：相亲时展示房子/瓷瓦的社交价值
**语言特征**：
- 夸张热情
- 不停地"你看你看！"
- 最终结论干脆有力

**示例台词**：
```

"这小伙子，不得了！"
"（对方妈妈）嗯，这个靠谱！"
```

## 三、台词创作黄金法则

### 字数控制（极其重要！）
- **每句话 ≤ 10 个字**
- **全片台词 ≤ 4 句**
- **1-2 句最佳**（留白让画面说话）

### 台词反差套路
```
模式一：对比型
"（别人用的瓦）→ 三年就碎了"
"（卡地克）→ 几十年不换"

模式二：身份揭示型
"你这房子..."
"（停顿）...卡地克的瓦。"

模式三：无厘头型
"这枪..."
"挡住了。"
"因为这是瓷瓦。卡地克的。"

模式四：夸自建房型
"村里最好看的房子，就是我家！"
```

### 爆款台词案例库

| 类型 | 台词 |
|------|------|
| 质量型 | "一块瓦，挡住了一颗子弹。" |
| 面子型 | "村里人问：你家屋顶哪买的？" |
| 传家型 | "盖房子，是给后代盖的。" |
| 反差型 | "别人以为我在省钱，其实我在省心。" |
| 无厘头 | "从小到大，没见过这么硬的瓦。" |
| 爽剧型 | "这辈子，不能亏了自己的房子。" |

## 四、背景音乐选择指南

### 按场景推荐

| 场景 | 推荐 BGM 风格 | 抖音关键词 |
|------|--------------|-----------|
| 枪战动作 | 电子摇滚，爆炸感 | 史诗BGM |
| 衣锦还乡 | 国风大气弦乐 | 民族乐器 |
| 相亲喜剧 | 轻喜剧钢琴 | 搞笑背景音 |
| 工匠精神 | 古朴民乐 | 景德镇瓷文化 |
| 无厘头 | 反差音效（严肃→搞笑） | 出乎意料 |

### 节奏卡点技巧
- 台词说完后 0.5 秒 = 切到产品特写（最有力）
- BGM 高潮点 = Logo 出现时机
- 结尾3秒 = 音乐渐弱 or 突然静音（制造记忆）
