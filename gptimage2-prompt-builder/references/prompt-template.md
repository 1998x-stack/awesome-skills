# Prompt Templates

## Canonical Chinese prompt skeleton

```
[作品类型]，主题为「[主题/标题]」；[主体与场景]；采用[主风格/媒介/时代]，[构图/版式系统]；画面包含[关键元素1]、[关键元素2]、[关键元素3]；文字部分包括「[精确文字]」，需清晰可读、拼写准确、无乱码；[光影/色彩/材质/镜头]；整体呈现[情绪/叙事/商业用途]；[比例/输出规格]；要求细节完整、风格统一、主体一致、可直接作为[使用场景]。
```

## Poster / editorial prompt

```
[现代主义/包豪斯/法国新浪潮/复古街头]风格海报，标题为「[标题]」，主题是[主题]。采用大胆粗体排版、杂志式信息层级、强烈几何构图，[色彩组合]。画面点缀[几何元素/拼贴/撕纸/纹理]，包含[正文/标注/多语种样例/图表]，所有文字清晰可读、准确排版。整体具有[先锋/学术/品牌/城市杂志]气质，适合[发布会/宣传/信息图]使用。
```

## Realistic photography prompt

```
[35mm/闪光灯/电影感/微距]写实摄影，[地点/时间/天气]，[主体动作与姿态]。[镜头与构图]，[光线]，[背景环境]包含[道具/人群/交通/自然景观/UI屏幕]。强调真实材质、自然细节、胶片颗粒/景深/空气感，叙事氛围强，避免过度修饰。
```

## Infographic / educational prompt

```
杂志级科普信息图，主题为「[主题]」。通过[模块1]、[模块2]、[模块3]清晰解释[核心逻辑]；包含标题、步骤编号、箭头、图表、地图/公式/示意图、传闻与事实或结论标注。排版层级清楚，信息密度高但易读，所有中文与数字标签准确无误。
```

## Comic / storyboard prompt

```
[日式少年漫/复古美式漫画/现代都市独立漫画/绘本治愈风]分镜页面，讲述[故事场景]。包含[页数/画格结构]，角色形象在所有画格中保持一致；使用[动态线/网点/低饱和色/黑白线稿/电影感夜景]。对白/独白文字清晰可读，情绪递进明确，镜头包含远景、近景、特写与关键动作。
```

## Brand / product / travel prompt

```
高端品牌视觉物料，主题为「[品牌/地点/产品]」。融合生活方式摄影、优雅字体排版、地域文化符号与商业级品牌系统；包含[产品/菜单/模型/宣传文案/封面/网格陈列]。整体风格统一、留白克制、可直接用于商业宣传。
```
