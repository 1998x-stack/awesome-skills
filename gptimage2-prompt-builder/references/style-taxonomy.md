# Style Taxonomy and 47-Item Analysis

## Core GPT Image 2 prompt techniques inferred from the 47 examples

1. **Output format first**: The prompt usually starts with the artifact type: poster, magazine spread, comic page, photo, infographic, bookmark, classroom scene, character sheet, product grid.
2. **Exact text as an object**: Titles, labels, UI text, handwritten notes, speech bubbles, and multilingual samples are treated as concrete visual requirements, not optional captions.
3. **Style plus production context**: “现代主义海报” is strengthened by magazine body text, bold typography, geometric shapes, print texture, and commercial-use framing.
4. **Material specificity**: rice grains on burlap, pencil on lined paper, CRT monitors, halftone print, torn paper, glossy fashion lighting, foggy coast, handwritten classroom notes.
5. **Composition vocabulary**: grid, spread, panel, scrapbook, infographic module, central subject, surrounding windows, balanced characters, safety margin, crop line, bleed mark.
6. **Cross-domain collage**: science, art, history, culture, maps, anatomy, architecture, symbols, crystals, UI, design mockups can coexist if unified by layout and material logic.
7. **Camera realism controls**: 35mm, macro, flash snapshot, cloudy coast, night street, cinematic portrait, candid gathering, black-and-white documentary.
8. **Narrative prompt design**: many examples encode story beats: discovering a magic quill, rooftop life talk, lonely youth monologue, museum trip, Provence food adventure.
9. **Knowledge-to-visual conversion**: academic proof, GPT-1 paper, design trends, color analysis, wolf science, Cantor proof become designed visual artifacts.
10. **Consistency constraints**: consistent characters across panels, unified brand feel, coherent color palette, accurate text, no missing print marks, complete multi-angle reference sheets.
