# 常见字段的多种含义定义

## 概述

在AI教育领域，许多"常识性"字段在不同业务场景下有截然不同的含义。本文档列出常见字段的多种定义，用于字段对齐时的参考。

**使用方式**：
1. 识别用户需求中的核心字段
2. 查阅本文档获取该字段的常见含义
3. 结合业务场景推断最可能的含义
4. 与用户确认，必要时请用户提供准确定义

## 答案相关字段

### answer_analysis / 答案解析

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 评分场景 | 评分标准、给分点 | 列出得分点、扣分项、分值分配 |
| **教学场景**（常见） | 解释答案背后的原理、逻辑、解题方法 | 说明如何解题、破题，指出考查要点、易错点、注意事项 |
| 自学场景 | 详细的推导过程 | 完整展示从题目到答案的每一步推理 |

**推荐默认定义（教育场景）**：
```
answer_analysis：解释答案背后的原理、逻辑或方法，说明如何解题、破题，指出本题的考查要点、易错点和注意事项。不是简单的评分标准或给分点。
```

### explanation / 解释

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 概念解释 | 对术语或概念的定义说明 | 简洁、准确、易懂 |
| 答案解释 | 为什么选这个答案 | 阐述选择理由、排除其他选项的原因 |
| 过程解释 | 步骤的详细说明 | 解释每一步在做什么、为什么这样做 |

### hint / 提示

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 引导式提示 | 帮助学生自己发现答案的线索 | 不直接给出答案，启发思考方向 |
| 解题提示 | 提供关键的解题入口或方法 | 指出切入点，但不完整解答 |
| 知识提示 | 与本题相关的知识点回顾 | 列出需要用到的公式、定理、概念 |

**推荐默认定义**：
```
hint：引导学生独立思考的线索，不直接给出答案，而是启发思考方向或提供解题的关键切入点。
```

## 题目相关字段

### difficulty / 难度

| 定义方式 | 说明 | 典型值 |
|---------|------|--------|
| 等级制 | 离散的难度等级 | easy/middle/difficult 或 1-5级 |
| 数值制 | 连续的难度系数 | 0.0-1.0 |
| 描述制 | 基于目标群体的描述 | "适合初学者"、"适合竞赛选手" |

**推荐默认定义**：
```
difficulty：题目难度等级，分为：
- easy（基础）：直接考查单一知识点，计算步骤≤3步
- middle（中等）：综合2-3个知识点，计算步骤4-6步
- difficult（提高）：综合多个知识点，需要多步推理或创新思维
```

### question_type / 题型

| 场景 | 定义 | 典型值 |
|-----|------|--------|
| 形式分类 | 按答题形式分类 | choice（选择）、fill_blank（填空）、short_answer（简答）、essay（论述） |
| 能力分类 | 按考查能力分类 | recall（记忆）、comprehension（理解）、application（应用）、analysis（分析） |
| 学科分类 | 按学科特点分类 | calculation（计算）、proof（证明）、experiment（实验）、reading（阅读） |

### stem / 题干

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 完整题干 | 包含所有必要信息的题目文本 | 背景、条件、问题完整 |
| 核心问题 | 只包含问题部分 | 不含背景材料 |

### options / 选项

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 带标签 | 包含选项标签 | ["A. 选项1", "B. 选项2", ...] |
| 纯内容 | 不含选项标签 | ["选项1", "选项2", ...] |
| 结构化 | 选项与标签分离 | [{"label": "A", "content": "选项1"}, ...] |

## 知识相关字段

### knowledge_point / 知识点

| 场景 | 定义 | 粒度 |
|-----|------|-----|
| 细粒度 | 单一、原子化的知识单元 | "勾股定理"、"一元二次方程求根公式" |
| 粗粒度 | 知识主题或章节 | "三角形"、"方程" |
| 考纲关联 | 与考试大纲对应的知识点 | 按课标或考纲编号 |

**推荐默认定义**：
```
knowledge_point：本题考查的核心知识单元，应为原子化的知识点（如"勾股定理"），而非宽泛的知识主题（如"三角形"）。
```

### prerequisite / 前置知识

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 知识依赖 | 学习本知识点前需要掌握的知识 | 列出知识点名称或ID |
| 能力依赖 | 需要具备的能力基础 | 如"基本运算能力"、"空间想象能力" |

### importance / 重要程度

| 定义方式 | 说明 | 典型值 |
|---------|------|--------|
| 等级制 | 离散的重要性等级 | high/medium/low |
| 考频制 | 基于考试出现频率 | 高频/中频/低频 |
| 权重制 | 数值化的重要性权重 | 1-10 或 0-100 |

## 内容相关字段

### summary / 摘要

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 内容概括 | 对原文的简短概括 | 保留核心信息，大幅压缩篇幅 |
| 要点提取 | 列出关键要点 | 结构化的要点列表 |
| 结论总结 | 得出的结论或观点 | 分析后的判断或建议 |

### category / 分类

| 场景 | 定义 | 内容要求 |
|-----|------|---------|
| 学科分类 | 所属学科或领域 | 数学、物理、化学等 |
| 内容分类 | 内容类型 | 概念、公式、定理、例题等 |
| 难度分类 | 按难度分组 | 基础、进阶、拓展 |

## 字段定义写入模板

确认字段含义后，在Prompt中添加【字段定义】模块：

```
【字段定义】
以下是各输出字段的准确含义，请严格按照定义生成内容：

- answer_analysis（答案解析）：解释答案背后的原理、逻辑或方法，说明如何解题、破题，指出本题的考查要点、易错点和注意事项。不是评分标准。

- hint（提示）：引导学生独立思考的线索，不直接给出答案，启发思考方向或提供解题切入点。

- difficulty（难度）：
  * easy：直接考查单一知识点，计算步骤≤3步
  * middle：综合2-3个知识点，计算步骤4-6步  
  * difficult：综合多知识点，需多步推理

- knowledge_point（知识点）：本题考查的原子化知识单元，如"勾股定理"，而非宽泛主题如"三角形"。
```

## 字段对齐检查清单

进行字段对齐时，检查以下要点：

- [ ] 是否提取了所有核心输出字段？
- [ ] 每个字段是否给出了明确定义？
- [ ] 定义是否符合用户的业务场景？
- [ ] 是否与用户确认了字段含义？
- [ ] 对齐后的定义是否写入了Prompt？
- [ ] 字段定义是否足够具体，避免歧义？
