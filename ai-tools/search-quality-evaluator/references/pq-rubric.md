# Page Quality (PQ) 评分细则

## Lowest（最低质量）

**特征（满足任一即为 Lowest）**：

### 有害内容
- 宣扬仇恨、歧视特定群体
- 煽动或美化暴力
- 涉及儿童性剥削
- 危险的错误医疗/健康信息（如反疫苗、危险疗法）
- 可能影响公共安全的严重错误信息

### 不可信页面
- 欺骗性目的（假装是新闻/官方机构的冒充站）
- 欺骗性设计（隐藏真实目的）
- 刻意遮挡主要内容（须点击/付费才能看到）
- 疑似恶意行为（恶意软件、钓鱼）
- 对于页面目的而言，关于网站/创作者的信息严重不足

### Spam 类型
| 类型 | 识别特征 |
|------|---------|
| 无内容/无目的 | 页面没有主要内容，或无法确定其存在的目的 |
| 被黑/被篡改 | 内容明显由黑客注入，与正常网站内容格格不入 |
| 过期域名滥用 | 已废弃的权威域名被购买后填充低质内容 |
| 站点声誉滥用 | 在高权威网站上发布完全无关的赞助/低质内容 |
| 规模化内容滥用 | 明显是大量 AI 生成或程序生成的无价值内容 |
| 低努力复制内容 | 直接抄袭，无任何转化或附加价值 |

**评分**：PQ = 0 - 1.0（Lowest 区间）

---

## Low（低质量）

**特征（多项组合或单项明显）**：

### 缺乏 E-E-A-T
- 作者无法验证其具有相关经验或专业知识
- 内容显示出对主题的误解或表浅理解
- 对于 YMYL 主题，无专业资质背书

### 低质量主要内容
- 内容明显是快速堆砌，缺乏深度
- 大量填充词（Filler）：废话、重复、凑字数的段落
- 内容有用但不完整，令用户不满足
- 标题夸大，正文不匹配（轻度 Clickbait）

### 其他低质量信号
- 关于网站/创作者的信息量严重不足（不是完全缺失，但非常少）
- 网站或创作者有轻微负面声誉
- 广告或辅助内容干扰主要内容的阅读

**评分**：PQ = 1.0 - 2.0（Low 区间）

---

## Medium（中等质量）

**特征**：
- 无任何 Lowest 或 Low 特征
- 内容尚可但不突出
- E-E-A-T 可接受但不够强
- 对于普通主题（非 YMYL）内容基本满足需求

**典型情况**：
- 一篇关于普通生活话题的博客文章，写得不错但没有专业深度
- 一个中小型网站上的产品介绍，信息完整但无独特价值
- 维基百科上的一个非热门主题条目（信息尚可但不够详细）

**评分**：PQ = 2.0 - 3.0（Medium 区间）

---

## High（高质量）

**必须同时满足**：

### 高质量主要内容
- 内容准确、完整、对目标受众有价值
- 写作专业，组织清晰
- 充分实现了页面的目的

### 正面声誉
- 创作者或网站在领域内有良好声誉
- 可找到正面的外部引用或评价

### 高 E-E-A-T
- 有明确的亲身经验或专业知识证明
- 被同行或机构认可
- 对于 YMYL 主题：具备相关专业资质

**评分**：PQ = 3.0 - 3.5（High 区间）

---

## Highest（最高质量）

**需要全部达到**：

### 极高质量主要内容
- 内容非常令人满意，独特且富有价值
- 展示出对主题的深刻理解
- 可能是该主题的权威参考来源

### 非常正面的声誉
- 在领域内被广泛认可
- 获得重要奖项或机构认可
- 被权威来源引用

### 极高 E-E-A-T
- 领域顶级专家，或
- 行业公认权威机构，或
- 具有真实、深度、独特的亲身经验

**评分**：PQ = 3.5 - 4.0（Highest 区间）

---

## YMYL 调整规则

```
if is_ymyl:
    if eeat_avg < 1.0:
        pq_level = "Lowest"  # 强制降级
    elif eeat_avg < 1.5:
        pq_level = 降一级  # 如 Medium → Low
    # High/Highest 标准提高：需要更强的专业资质证明
```
