# E-E-A-T 评估详细清单

## 框架概述

E-E-A-T = Experience + Expertise + Authoritativeness + Trustworthiness

**核心原则**：Trustworthiness（可信度）是最根本的维度，其他三个维度共同支撑可信度。

---

## Experience（经验）评估清单

### 强信号（各+0.5分，上限2分）

- [ ] 作者描述了**亲身使用**产品/服务的体验
- [ ] 内容包含**真实照片**或**第一手视觉证据**
- [ ] 提到了**具体的个人情景**（时间、地点、经过）
- [ ] 描述了**试错过程**或遇到的**具体问题**
- [ ] 对比了**多个同类产品**（显示真实使用过多个）
- [ ] 内容包含**使用心得**而非仅规格参数

### 弱信号或缺失信号

- 内容仅转述他人经验或媒体报道
- 内容看起来基于搜索整合，无亲历成分
- 产品评测但无实物照片，仅使用官方图

---

## Expertise（专业知识）评估清单

### 强信号（各+0.5分，上限2分）

- [ ] 作者有**明确的专业背景**（学位、执照、认证）
- [ ] 内容展示出**深度专业理解**（非表面知识）
- [ ] 内容**引用了同行评审研究**或权威数据
- [ ] 作者在该领域有**实践工作经验**
- [ ] 内容涵盖**专业术语并正确使用**
- [ ] 能够解释**为什么**，而不仅仅是**什么**

### YMYL 额外要求

| 领域 | 所需专业背景 |
|------|------------|
| 医疗 | 执业医师、注册护士、医疗机构 |
| 法律 | 执业律师、法律机构 |
| 财务 | 持牌金融顾问、CFA/CFP 认证 |
| 心理健康 | 执照心理咨询师、精神科医生 |
| 工程/建筑 | 注册工程师/建筑师 |

---

## Authoritativeness（权威性）评估清单

### 强信号（各+0.5分，上限2分）

**创作者权威性**：
- [ ] 被同行或行业媒体**引用**
- [ ] 在主要出版物发表过**署名文章**
- [ ] 获得**行业奖项**或认可
- [ ] 拥有**大量追随者**（与领域相关的平台）
- [ ] 在领域内有**演讲或教学**经历

**网站权威性**：
- [ ] 被权威网站（.gov/.edu/主流媒体）链接
- [ ] 长期运营，**历史声誉**良好
- [ ] 有**维基百科条目**（且内容正面）
- [ ] 被新闻媒体**正面报道**

---

## Trustworthiness（可信度）评估清单

### 页面级别可信度

**必要信息（缺失则严重降分）**：
- [ ] 有准确的**作者信息**
- [ ] 有**发布/更新日期**
- [ ] 内容引用**来源**（链接或标注）
- [ ] 声明是否含**广告/赞助内容**

**加分项**：
- [ ] 外部链接指向**权威来源**
- [ ] 涉及争议话题时**呈现多方观点**
- [ ] 有**纠错或更新**机制
- [ ] 方法论/研究过程**透明**

### 网站级别可信度

**基础要求**：
- [ ] 清晰的**关于我们（About）**页面
- [ ] **有效的联系方式**（邮件/电话/地址）
- [ ] **隐私政策**页面
- [ ] **HTTPS** 安全连接
- [ ] 编辑政策或**内容准确性声明**（媒体类网站）

**电商类额外要求**：
- [ ] **退款/退货政策**清晰
- [ ] **安全支付**标志
- [ ] **真实用户评价**（而非全5星无评论）

### 负面信号（降低可信度）

- 内容有**明显事实错误**
- 作者信息**无法验证**
- 网站有**消费者投诉记录**
- 存在**夸大或误导性**标题
- 内容**主要目的是推广**而非提供价值
- 使用**隐藏文字**或其他欺骗性 SEO 技术

## 常见 E-E-A-T 误区

| 误区 | 正确理解 |
|------|---------|
| 字数多 = 高质量 | 内容深度和准确性比字数更重要 |
| 有图片 = 有经验 | 图片需要是真实亲历的，使用官图不算 |
| 高流量网站 = 高权威 | 权威性来自领域认可，不是流量 |
| AI 生成内容一定差 | AI 内容若准确、有价值，仍可获高分；关键是质量 |
| 有联系方式 = 可信 | 可信度是综合信号，单一要素不够 |
