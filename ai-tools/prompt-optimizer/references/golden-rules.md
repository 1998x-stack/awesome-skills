# 10 条黄金法则详细参考

快速索引：优化时按需读取对应法则章节。

## 法则 1：结构化优先

使用 XML 标签或 Markdown 标题划分功能模块。
推荐模块顺序：`<role>` → `<context>` → `<rules>` → `<task>` → `<examples>` → `<output_format>`

## 法则 2：角色锚定三维

- **专业身份**：具体职位 + 经验年限 + 专注领域
- **行为风格**：表达风格 + 详略偏好
- **价值取向**：首要目标 + 核心原则

## 法则 3：示例驱动（Few-Shot）

- 3-5 个示例覆盖主要变体
- 示例应多样（Diverse）、信息密（Dense）、有难度梯度
- 打乱顺序防止位置偏见

## 法则 4：思维链激活

```xml
在 <thinking> 中展示推理（内部），在 <answer> 中给出结论
```
或使用"请一步一步分析"触发。

## 法则 5：输出格式约束

- 提供 JSON Schema + 具体示例
- 流式输出必须包含 order 字段
- 禁止包含 ```json 包装符（若需直接解析）

## 法则 6：上下文工程

4层架构：系统指令 → 知识注入 → 对话历史 → 用户输入
长对话需 Compaction + 关键规则重注入

## 法则 7：防御性提示

三层防护：注入防护 + 幻觉抑制 + 边界约束
见 SKILL.md 中的防御模板

## 法则 8：模块化变量化

`{{variable_name}}` 占位符 + Category Variable 模式
逻辑外置，Prompt 保持干净

## 法则 9：迭代评估体系

测试集 60/25/15 分布 + LLM-as-Judge 自动化评估
不迭代的优化不是优化

## 法则 10：模型适配策略

见 references/model-adaptations.md 详细策略
