# 字段定义对齐参考

## 对齐流程

提取输出字段 → 给出默认定义 → 用户确认/修正 → 嵌入 Prompt

### 对齐模板

```
我从您的需求中提取了以下核心字段，请确认含义是否正确：

| 字段名 | 我的理解 | 是否正确？|
|-------|---------|----------|
| ... | ... | ✓/✗ |
```

## 常见字段多义词典

| 字段名 | 常见含义 A | 常见含义 B | 确认方式 |
|--------|-----------|-----------|---------|
| `answer_analysis` | 评分标准/给分点 | 解题原理/思路/考查要点 | 询问是否面向学生 |
| `difficulty` | 1-5 数值评分 | easy/medium/hard 枚举 | 确认前端展示方式 |
| `summary` | 全文摘要 | 核心结论一句话 | 确认目标用途 |
| `explanation` | 结果的解释 | 过程的说明 | 确认是答案还是过程 |
| `score` | 百分制数字 | 等级评定 | 确认评分体系 |
| `category` | 主题分类 | 难度分类 | 确认分类维度 |
| `tags` | 关键词标签 | 功能标签 | 确认使用场景 |
| `confidence` | 0-1 浮点 | 高/中/低枚举 | 确认下游消费方式 |

## 字段定义写入 Prompt 格式

```
【字段定义】
- field_name（中文名称）：精确的业务含义描述。
  不是 X（排除常见误解），而是 Y（正确理解）。
```

示例：
```
【字段定义】
- answer_analysis（答案解析）：解释答案背后的原理、逻辑或方法，
  说明如何解题、破题，指出本题考查要点和注意事项。
  不是评分标准或给分点，而是帮助学生理解"为什么"。
- difficulty（难度）：分为 easy（基础）、medium（中等）、hard（提高）
  三档，反映题目的综合度和思维深度。
```
