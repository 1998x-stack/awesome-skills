# Example prompts and response shapes

## Example 1: turn a vague idea into a concept

### Input
I want a co-op exploration game about rebuilding a dead city.

### Output shape
- one-paragraph concept
- target emotions across early, middle, late play
- core loop in 4 steps
- 3 differentiators
- 3 biggest risks
- smallest prototype

## Example 2: critique a feature

### Input
Our extraction game has full-loot pvp, but we also want warmth and long-term friendship.

### Output shape
- diagnosis of fantasy contradiction
- which systems currently reward betrayal or anxiety
- two redesign paths: conservative and bold
- validation plan with playtest goals

## Example 3: analyze in a Jenova-inspired way

### Input
Analyze this game pitch using Journey and Sky style design thinking.

### Output shape
- target human feeling
- real-life relevance
- emotional arc stages
- flow and agency review
- prosocial multiplayer review
- monetization or retention conflicts
- revised concept statement
